# Book Story – Landing page (Alpha Books)

Landing page tĩnh (1 file `index.html`, ảnh nhúng base64). Lead gửi về Google Apps Script → Sheet tab "Thông tin đăng ký".

## Deploy lên Vercel
1. Push repo này lên GitHub.
2. Vercel → Add New Project → Import repo → Framework Preset: **Other** → Deploy (không cần build command, output là thư mục gốc).
3. Mỗi lần push lên `main` Vercel tự deploy lại.
